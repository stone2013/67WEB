# 67WEB

Simple static landing page for `67VIP`.

## Overview

This repository contains a single-page HTML site for a `67VIP` membership / recharge landing page.

## Files

- `index.html` - the main landing page

## Usage

Open `index.html` directly in a browser, or deploy it to any static hosting service such as GitHub Pages.

## Customization

You can update the following in `index.html`:

- page title and branding
- membership price and benefits
- contact link or payment link
- colors, layout, and text
