# 67WEB

Simple static landing page for `67VIP`.

## Overview

This repository contains a static `67VIP` site built for GitHub Pages, including a landing page and a mock member dashboard.

## Files

- `index.html` - the main landing page
- `dashboard.html` - a mock member center / dashboard page

## Usage

Open `index.html` directly in a browser, or deploy the repository to any static hosting service such as GitHub Pages.

## Customization

You can update the following in `index.html`:

- page title and branding
- membership price and benefits
- contact link or payment link
- colors, layout, and text
- dashboard metrics and mock member data
